Primavera P6 Professional Basic Training

Get your team productive with Primavera P6 in just 3 days

Primavera P6 Professional Basic Training will give your staff all the tools they need to start working with the system effectively within a few days. This hands-on course covers the fundamentals of project planning, scheduling, and resource management.

Learning Outcomes

Create Projects

Build a project with activities and resources

Calculate Schedules

Schedule projects using CPM methodology

Analyze Data

Analyze resource and cost data

Track Progress

Compare current vs. target schedules

Course Topics

  • Adding projects to the Project Structure
  • Creating a Work Breakdown Structure
  • Adding Activities
  • Adding Codes to Activities
  • Creating Relationships
  • Schedule a Project
  • Adding Constraints
  • Organize Activities
  • Assign Resources and Costs
  • Analyze Resource/Cost Usage
  • Status the Project
  • Mitigate the schedule
  • Analyze the updated Project
  • Generating Reports

Course Duration

3 Days
